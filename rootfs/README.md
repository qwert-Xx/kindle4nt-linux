# K4 root inputs from source

`k4/` stores the exact public K4 scripts/configuration bytes, with REUSE sidecars kept out of the root. `src/` and `programs.json` rebuild the K4 ELF probes. `stage.py` copies only those sources and explicit external firmware/SSH/Wi-Fi inputs; it consumes no existing root tar. Service definitions are generated by project/alpine/build.py. Official Alpine packages are authenticated distribution inputs. The source-built maintenance BusyBox and Dropbear are also built by project/release.py; Alpine retains its own authenticated BusyBox/Dropbear packages.
